# Extension Changer

A simple console-based Java application that allows users to change the file extension of one or multiple files quickly and efficiently.

## Features

- Change the extension of a single file
- Batch process multiple files
- Input validation
- Error handling
- Console-based interface

## Technologies Used

- Java SE
- Core Java
- Java I/O
- Java NIO

## Getting Started

### Prerequisites

- Java JDK 8 or later

### Installation

1. Clone the repository.
2. Open the project in your preferred Java IDE.
3. Compile and run the application.

## Example

**Input**

```
Enter file path:
C:\Users\User\Documents\sample.txt

Current Extension: .txt
New Extension: pdf
```

**Output**

```
Extension changed successfully!
New File: sample.pdf
```
