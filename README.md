# Java Utility Applications

A collection of practical **console-based Java SE utility applications** built using **Core Java**. This repository contains lightweight tools designed to automate common tasks, demonstrate Java programming concepts, and showcase clean, modular code.

## Utilities

### 1. Extension Changer
A utility that changes the extensions of one or more files quickly and efficiently.

**Features**
- Batch file extension renaming
- Input validation
- Error handling
- Console-based interface

---

### 2. Word to PDF Converter
A utility that converts Microsoft Word (`.docx`) documents into PDF format.

**Features**
- Convert Word documents to PDF
- Simple command-line interaction
- Fast and reliable conversion

---

## Technologies Used

- Java SE
- Core Java
- Java I/O (File Handling)
- Java NIO
- Apache POI *(if used)*
- PDF Conversion Library *(if used)*
